Das vorliegende Respository enthält Python Code, welcher im Rahmen eines Semesterprojekts erstellt wurde.
Konkret wird ein Fully Connected Neuronal Network gefolgt von einem Deconvolutional Neuronal Network durch Supervised Learning trainiert.
Das Model erzeugt eine 2D Heatmap.
Die erzeugte Heatmap wird anschließend durch einen Gruppierungsalgorithmus gruppiert und die Gruppierung evaluiert.
Mit Hilfe des Evaluierungsmaßes werden die Inputvariablen optimiert.
